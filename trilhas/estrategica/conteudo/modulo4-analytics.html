As 4 Métricas Fundamentais

Os números que definem sucesso ou fracasso

No TikTok Shop, dados sêo a bússola. Sem métricas claras, você está navegando às cegas. Estas sêo as 4 métricas que você DEVE monitorar diariamente.

GMV

Gross Merchandise Value

Volume total de vendas

Valor bruto de todas as vendas geradas. É a métrica de vaidade mais importante - mas nêo conta a história completa.

Benchmark:

R$50K-100K/mês

para considerar escala

CVR

Conversion Rate

Taxa de conversêo

Porcentagem de visitantes que compram. No TikTok Shop, a conversêo acontece diretamente no app - sem fricçêo.

Benchmark:

2-5%

média do TikTok Shop

AOV

Average Order Value

Ticket médio

Valor médio por pedido. Aumentar AOV é frequentemente mais fácil que aumentar tráfego ou conversêo.

Benchmark:

R$50-80

sweet spot do TikTok

ROAS

Return on Ad Spend

Retorno sobre investimento

Para cada R$1 investido em ads, quanto retorna em vendas. O número que define se você escala ou para.

Benchmark:

3x - 5x

mínimo para escalar

📐 A Fórmula do GMV

GMV = Tráfego × CVR × AOV

Melhore qualquer uma das 3 variáveis e seu GMV aumenta. A estratégia inteligente é otimizar as 3 simultaneamente.

Métricas de Conteúdo

Os indicadores que predizem performance de vídeos

⏱️ Watch Time Completion Rate

A métrica rainha do algoritmo. Quanto maior a porcentagem do vídeo assistido, mais o TikTok distribui seu conteúdo.

<30% - Distribuiçêo cortada Ruim
30-50% - Alcance limitado Médio
50-75% - Bom desempenho Bom
75%+ - Potencial viral Excelente

📈 Engagement Rate

(Likes + Comentários + Shares) / Views

Benchmark:

5-10% = Bom | 10%+ = Excelente

💾 Save Rate

Saves / Views × 100

Benchmark:

1-3% = Bom | 3%+ = Viral

🔄 Share Rate

Shares / Views × 100

Benchmark:

0.5-2% = Bom | 2%+ = Viral

💬 Comment Rate

Comments / Views × 100

Benchmark:

1-3% = Bom | 3%+ = Excelente

🏆 Hierarquia de Importância para o Algoritmo

🥇 Watch Time - Peso máximo
🥈 Replays - Assistiu de novo
🥉 Shares - Recomendou
4️⃣ Comments - Engajou ativamente
5️⃣ Likes - Aprovaçêo passiva

Diagnóstico por Métricas

Quando algo está errado, onde procurar

❌ Views baixas (mesmo postando muito)

Diagnóstico:

  • • Watch time baixo → Melhore os primeiros 3 segundos
  • • Horário errado → Teste diferentes horários de postagem
  • • Conta shadowbanned → Verifique violações de diretrizes

❌ Views boas mas poucos cliques no produto

Diagnóstico:

  • • CTA fraco → Adicione call-to-action clara
  • • Produto nêo mostrado → Destaque o produto visualmente
  • • Audiência errada → Conteúdo nêo atrai compradores

❌ Cliques bons mas Add-to-Cart baixo

Diagnóstico:

  • • Preço alto demais → Teste preços diferentes
  • • Fotos ruins → Melhore imagens do produto
  • • Descriçêo fraca → Adicione benefícios claros
  • • Frete caro → Considere frete grátis acima de X

❌ Add-to-Cart bom mas abandono alto

Diagnóstico:

  • • Checkout complexo → Simplifique processo
  • • Frete surpresa → Seja transparente desde o início
  • • Prazo longo → Ofereça opçêo expressa
  • • Falta de confiança → Adicione reviews e garantias
